# Как помочь

Здесь нет кода сайта, но можно улучшить SDK, примеры и документацию.

1. Форкни репозиторий и создай ветку.
2. Поставь зависимости и проверь, что всё собирается:
   ```bash
   npm install
   npm run typecheck
   npm test
   npm run build
   ```
3. Код на TypeScript без лишних зависимостей, тексты на русском.
4. Открой pull request и опиши, что изменилось и зачем.

Ошибки на сайте и идеи отправляй через [issues](../../issues/new/choose). Об уязвимостях сообщай приватно, см. [SECURITY.md](SECURITY.md).
