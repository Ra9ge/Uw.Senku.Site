# Как помочь

Здесь нет кода сайта, но можно улучшить SDK, примеры и документацию.

1. Форкни репозиторий и создай ветку.
2. Поставь зависимости и проверь, что всё собирается:
   ```bash
   npm install
   npm run typecheck
   npm test
   npm run build
   ```
3. Пиши коротко и понятно: код — на TypeScript без лишних зависимостей, тексты — на русском.
4. Открой pull request и опиши, что изменилось и зачем.

Ошибки на самом сайте и идеи — через [issues](../../issues/new/choose). Уязвимости — только приватно, см. [SECURITY.md](SECURITY.md).
